INF653 Final REST API

API Endpoint Reference
Method Endpoint Description
GET /states/ All state data returned
/states/?contig=true All state data for contiguous states
/states/?contig=false All state data for non-contiguous states
/states/:state All data for the state URL parameter
/states/:state/capital { 'state': stateName, 'capital': capitalName }
/states/:state/nickname { 'state': stateName, 'nickname': nickname }
/states/:state/population { 'state': stateName, 'population': population }
/states/:state/admission { 'state': stateName, 'admitted': admissionDate }
/states/:state/funfact A random fun fact for the state URL parameter
POST /states/:state/funfact Add an array of new fun facts
PATCH /states/:state/funfact Update a fun fact using a 1-based index
DELETE /states/:state/funfact Remove a fact using a 1-based index
